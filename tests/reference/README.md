# Runtime reference batch

`plain/` is generated from its saved plan with Python 3.14.6, Faker 37.12.0,
and Astrea 0.1.0. It is distinct from the hand-authored design example.

The regression suite compares regenerated bytes on this Python version. Review
changes to both `.eml` bytes and manifest expectations when intentionally changing
the renderer, templates, catalog, or dependencies. Other supported Python versions
still run structural and replay tests without promising byte identity to this one.
